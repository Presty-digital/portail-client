# Presty CRM V20.4

Évolution UI des intégrations agence :

- GoHighLevel : bouton « + Installer sur d’autres sous-comptes » ouvrant directement la fiche d’installation Presty CRM dans HighLevel.
- Meta Ads : bouton « + Affecter de nouveaux éléments » ouvrant directement les Utilisateurs système du portefeuille Meta Business Presty Digital.
- Les deux liens s’ouvrent dans un nouvel onglet afin de conserver l’administration Presty ouverte.
- Les boutons de rafraîchissement et leurs états de synchronisation restent inchangés.

Cette version reprend la V20.3 et ne modifie pas la logique OAuth/token ni les API de synchronisation.
