# Presty CRM V21.6

- Suppression de l’onglet Statistiques : les statistiques utiles sont intégrées au Tableau de bord.
- Suppression du bloc « Rendez-vous sur la période ».
- Nouveau funnel : Prospects → Décrochés → RDV pris → RDV présentés → Gagnés.
- « Décroché » est un jalon configurable du pipeline, pas un statut : Paramètres > CRM permet de placer le seuil visuellement entre les étapes.
- Une opportunité qui franchit le seuil conserve `contactedAt`, donc reste comptée comme décrochée même si son statut change ensuite.
- Performance commerciale par catégorie intégrée au Tableau de bord.
- Bloc « Actions à traiter » avec Fait / Modifier.
- Bloc « Rendez-vous passés à mettre à jour » avec actions rapides Réalisé / No-show / Gagné.
- Structure fixe et responsive V21.5 conservée pour desktop, tablette et mobile.
