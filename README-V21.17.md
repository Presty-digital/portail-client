# PRESTY CRM V21.17

Base : V21.16.

## Modifications
- Fiche contact : suppression du badge de catégorie dans le bloc identité/coordonnées.
- Suivi des demandes entièrement réorganisé en zones distinctes : statut, rendez-vous, prochaine action, notes du suivi.
- Ajout d’un commentaire propre à chaque action planifiée.
- Les commentaires généraux sont renommés « Notes du suivi » pour éviter toute confusion avec les commentaires d’action.
- Bouton « Ajouter l’action » recentré.
- Affichage de la note directement dans la liste des actions.
- Aucun changement des intégrations, du multi-tenant ou des données existantes.

Pack complet limité à 99 fichiers pour dépôt via GitHub Web puis déploiement Vercel automatique.
