# Presty CRM V21.4 — diagnostic Meta

Base : V21.3. Aucun changement sur le nouveau filtre de période Publicité.

Cette version enrichit uniquement le diagnostic de l’intégration Meta Ads :
- statut HTTP ;
- code et sous-code Meta ;
- type d’erreur ;
- version Graph API ;
- présence du token serveur ;
- message utilisateur Meta et FB Trace ID lorsqu’ils existent.

Le token n’est jamais affiché côté client.
