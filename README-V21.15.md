# PRESTY CRM — V21.15

Base : V21.14 finale.

## Changements

- Administration > Comptes clients : ajout d'une recherche instantanée sur le nom, le nom d'entreprise, l'email et la ville, sans rechargement.
- Administration > Utilisateurs : la page utilise désormais la coque `fixed-page` avec une zone de contenu verticale scrollable sur desktop, tablette et mobile.
- Aucun changement volontaire des intégrations Supabase, GoHighLevel ou Meta Ads, ni de la logique multi-tenant.
- Version npm : `21.15.0`.

## Validation

Exécuter `npm run build`. La version de livraison est considérée valide uniquement si le build Next.js se termine sans erreur.
