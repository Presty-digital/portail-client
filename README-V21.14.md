# Presty CRM V21.14 — Finale

- Nouvelle page **Actions du jour** : compteurs visuels, cartes compactes, actions et rendez-vous passés mieux hiérarchisés.
- Les rendez-vous à mettre à jour demandent explicitement le résultat du rendez-vous.
- Responsive mobile/tablette conservé et adapté à la nouvelle présentation.
- L’administrateur peut désormais modifier le **nom du compte client** depuis `Comptes clients > Configurer`.
- Le nouveau nom est enregistré sur `name` et `companyName`, donc réutilisé dans l’espace client, la sidebar et le sélecteur de comptes.
- Domaine de production conservé : `https://portail-client.presty-digital.fr`.
