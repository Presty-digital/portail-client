# Presty CRM V21.7

- Ajout d’un onglet client **Actions** séparé du tableau de bord.
- Actions à traiter + rendez-vous passés à confirmer centralisés dans cet onglet.
- Le bouton **Modifier** ouvre désormais directement la fiche contact.
- Correction d’un effet de réapparition/disparition lors des sauvegardes rapides (protection contre les réponses de polling obsolètes).
- Archivage, restauration et suppression définitive d’un contact depuis sa fiche.
- Filtre Contacts actifs / archivés / tous dans la base Contacts.
- Les contacts archivés sont masqués du CRM, des rendez-vous et des actions actives.
- Dans Paramètres > Synchronisations, les sous-onglets GoHighLevel / Meta restent visibles en haut pendant le scroll du bloc et l’espacement avec le panneau est harmonisé.
